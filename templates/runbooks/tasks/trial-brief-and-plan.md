# Write and Review the Trial Brief and Plan
**Owner:** researcher. **Reviewers:** the team's chosen reviewers and relevant stakeholders.

## Instructions and Completion Criteria
- [ ] Link the parent project brief and the trial's working documents from the task.
- [ ] Write the trial brief and the plan for the researcher-selected method: interview, survey, or user testing. Explain the questions, participant selection, collection process, and intended use of the evidence.
- [ ] Request team review and hand responsibility to the named reviewer. Return requested revisions to the researcher, repeat as needed, and record approval.
- [ ] Request the agreed stakeholder review and hand it to the named reviewer. Return requested revisions to the researcher and record the outcome.
- [ ] Resolve required changes and identify the reviewed versions before collection begins. For a survey, include review/piloting of the questionnaire and response options; for sessions, include the guide or tasks and materials.
- [ ] Hand the reviewed plan to the recruitment and collection owners. Record any review role that does not apply.

**Document templates:** `templates/trial-brief.md` and the selected `templates/trial-plan-*.md` from the toolkit root.
