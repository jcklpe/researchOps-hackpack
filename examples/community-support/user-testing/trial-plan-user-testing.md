# Trial Plan: User Testing
**Trial:** [Trial brief](trial-brief.md)
**Subject:** Imaginary community-center information page, fictional v1
**Duration:** 15 minutes in this demonstration

## Intro
Explain that we are examining the service information, not the participant's ability. Introduce the observer, invite the participant to stop or skip, and agree how notes will be used. The example assumes notes without recording.

## Materials and Starting Point
Imagine a page with links titled “Resident Services,” “About Us,” and “Contact.” The Contact page displays a telephone number and a sentence saying staff can help determine what support is relevant. This is a description for reading the example, not an implemented prototype.

## Task: Ask About Food Support
- Participant prompt: “You want to find out whether the center can help you with groceries. Show me how you would take the next step.”
- Starting point: the imaginary page described above.
- Observe: route selected, uncertainty, and whether the participant can explain what to do next.
- Completion criterion: find the phone number and explain that calling can clarify available support.
- Assistance: allow exploration; if the participant asks for help, give a neutral prompt and record it. Stop if they wish to stop. Do not count assisted completion as independent completion.
- Follow-up: “What did you expect to happen when you chose that link?”

## Debrief and Closing
Compare observer notes with the task criterion and record assistance. Thank the participant and allow time for questions. These are invented sample materials, not questions or task choices for a real project.
