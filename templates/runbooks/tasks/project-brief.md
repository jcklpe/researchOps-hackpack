# Write and Review the Project Brief
**Owner:** researcher. **Reviewers:** the team's chosen reviewers and relevant stakeholders.

## Instructions and Completion Criteria
- [ ] Prepare a shared working document from the project-brief template and link it from the task. It may be Markdown or the team's chosen document format.
- [ ] Write the background, goals, intended use, assumptions, and timeframe. The researcher supplies the inquiry.
- [ ] Request team review and hand responsibility to the named reviewer. Record comments and requested changes.
- [ ] Return responsibility to the researcher for revisions; repeat review as needed and record team approval.
- [ ] Request the agreed stakeholder review, hand it to the named reviewer, and resolve requested revisions with the researcher.
- [ ] Record the agreed approval or why a review role does not apply, and link the final working brief from the project's grouping.

**Document template:** `templates/project-brief.md` from the toolkit root.
