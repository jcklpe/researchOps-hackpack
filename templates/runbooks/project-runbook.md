# Project Runbook
Use this when establishing a research project. Copy the tasks into the team's chosen working system and keep actual owners and status there. A project can span products, services, or teams.

## Setup Checklist
- [ ] Establish the project's grouping or epic using the [epic task](tasks/epic.md).
- [ ] Create a project folder and blank [project brief](../project-brief.md), manually or with the project-creation skill. Record its location in the grouping.
- [ ] Create the [project-brief task](tasks/project-brief.md) and associate it with the grouping.
- [ ] Assign each task an owner and agree who handles team and stakeholder review. For an individual project, record which responsibilities the researcher holds and whether external review applies.
- [ ] Verify that the owner can find the documents and the next action. Creating the tasks completes this runbook's setup, not the research work itself.

When the project brief is ready and a trial is chosen, use the [trial runbook](trial-runbook.md). Do not create a first trial merely because the project folder exists.
